添加设备

给这台设备起个名字，生成二维码后用 App 扫描。

每台设备用不同名称，可用字母、数字、短横线和下划线。

打开 Android App，点击「扫码配对」，
扫描二维码并确认服务地址。

二维码仅供你自己使用，请勿分享。

创建 push_key

为调用方创建发送密钥，用于 /notify 的 Bearer 鉴权。拥有密钥即可向所有设备发送通知，请妥善保管。

请立即复制保存，离开页面后无法再次查看。新建密钥不会替换已有密钥。
